# Use Case Submissions

Long-form, worked write-ups of applying the SCI for Web methodology to a
real or realistic web application land here as individual Markdown files,
one per submission. Start a submission via the `case-study-template` issue
form (see `.github/ISSUE_TEMPLATE/case-study-template.md`); once discussed
and reviewed per [`docs/ReviewProcess/Data.md`](../docs/ReviewProcess/Data.md),
the write-up is added here and linked from
[`docs/CaseStudies.md`](../docs/CaseStudies.md).
