**In short:** this page lists real-world SCI for Web assessments
submitted by the community. The [Worked Examples](./QuickGuide.md) use
hypothetical numbers to show the mechanics; case studies go further, with
real web applications, disclosed data sources, and the boundary and
allocation decisions a real assessment needed.

## Submitting a case study

Open an issue using the `case-study-template` issue form in this
repository. It follows the structure the specification uses for the
assessment itself: an overview, the architecture, the SCI for Web
components addressed (`O_server`, `O_client`, the optional `O_network`,
`M_server`, `M_network`, `M_client`), and the
Bound → Scale → Define → Quantify → Report procedure (Clause 4). A
submission therefore maps directly onto the concepts explained elsewhere
on this site.

Submissions are reviewed through the [Review Process](./ReviewProcess/Data.md)
before being added here and to `use-case-submissions/`.
